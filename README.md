## The pitch

> That app idea you've told your friends about a dozen times — say it one more time, in plain words, to an AI agent on make.fun, and it will hand you back a working first version you can actually try.

198 characters, one sentence.

## How it works

`main.py` (Python standard library only) writes the pitch — a fixed,
deterministic string — to `/output/entry.txt`, with no trailing newline.
Run it twice and the output is byte-identical:

```sh
python3 main.py
cat /output/entry.txt
```
